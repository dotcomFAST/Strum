# Strum Energy — концепт корпоративного сайту

Концепт сайту вигаданої української енергетичної компанії Strum Energy: сонячні станції та системи накопичення енергії для громад, бізнесу й критичної інфраструктури. Стиль — інтернаціональний типографічний (швейцарський): модульна сітка, гротеск, один сигнальний акцент.

> Компанія, цифри, проєкти, контакти й цитати вигадані. Фотографії згенеровані ШІ.

## Сторінки

| Файл | Сторінка |
| --- | --- |
| `index.html` | Головна |
| `solutions-communities.html` | Рішення для громад |
| `projects.html` | Проєкти: фільтр за типом, вигляд «сітка / таблиця / карта» |
| `project-hospital.html` | Кейс: багатопрофільна лікарня |
| `investors.html` | Інвесторам: показники, графік, звіти за роками, ESG |
| `contacts.html` | Контакти, відділи, форма |

## Структура

```
.
├── index.html …                 сторінки
└── assets/
    ├── css/styles.css           стилі (desktop і mobile)
    ├── js/main.js               фільтри, вкладки, форми
    ├── img/                     фотографії
    └── favicon.svg
```

Кожна сторінка містить дві розкладки: desktop (від 1200 px) і mobile (до 1199 px). CSS показує потрібну за шириною екрана. Анімації вимикаються, якщо в системі ввімкнено «зменшити рух».

## Запуск локально

Збирання не потрібне — це статичні файли.

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

Або просто відкрити `index.html` у браузері.

## Публікація на GitHub Pages

1. Створити репозиторій і завантажити в нього вміст цієї папки (файли в корені).
2. Settings → Pages → Source: **Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. Через хвилину сайт буде доступний за адресою `https://<username>.github.io/<repo>/`.

## Що не реалізовано

Сторінки «Про компанію», «Новини», «Кар'єра», англійська версія, PDF-звіти та відправлення форми на сервер — у концепті це заглушки.
